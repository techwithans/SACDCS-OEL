**Baseline:** v1.0 · **New version:** v1.1

Compare tags `v1.0-baseline...v1.1` on GitHub to see exact changes.

| CR | Req ID | Old text (v1.0) | New text (v1.1) | Reason | Status |
|---|---|---|---|---|---|
| CR-01 | FR-08 | The robot shall enter Safe Mode when battery is below 10 %, chamber temperature is critical, or a critical hardware fault occurs. | The robot shall enter Safe Mode **within 3 seconds** when chamber temperature is below 0 °C or above 12 °C, **battery temperature is above 60 °C**, or battery capacity falls below 10 % (emergency level). | CR-02 | NFR-03 | The system shall support communication with multiple robots simultaneously. | The system shall support **at least 20 simultaneously connected robots**, each still meeting NFR-01 timings (acknowledge ≤ 10 s, telemetry shown ≤ 15 s). | The pilot serves 20 clinics; "multiple" was not measurable. | **Modified** |
| CR-03 | FR-02 | Only authenticated operators shall be permitted to issue robot commands. | The system shall accept a robot command only if the operator is **authenticated (FR-01) and their role permits that command** (Viewer / Dispatcher / Supervisor). Every rejected command shall be logged with operator ID and reason. | Authentication alone would let a Viewer move a robot. | **Modified** |
