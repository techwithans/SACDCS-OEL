# Task 4.1 – Operations List

> Question: Identify at least 12 operations performed by the system. Do not use
> state names as operation names.

Operations are **actions (verbs)**. States are **conditions (nouns)**.
Example: `StartConservation` is an operation; `CH-CONSERVING` is a state.

| OP-ID | Operation | What it does |
|---|---|---|
| OP-01 | RunSelfCheck | Tests all essential sensors at power-on |
| OP-02 | LoadBatchProfile | Loads the batch ID and its temperature/humidity limits |
| OP-03 | StartConservation | Begins active conservation |
| OP-04 | ReadSensors | Reads temperature, humidity, vibration, door and power every 10 s |
| OP-05 | CorrectTemperature | Turns cooling or heating on |
| OP-06 | CorrectHumidity | Adjusts humidity |
| OP-07 | VerifyRecovery | Checks by sensor reading that the value is back in range |
| OP-08 | ActivateProtection | Protection response: reduce light, alert operator, quarantine batch |
| OP-09 | SuspendRiskyActivities | Pauses risky actions when vibration is high |
| OP-10 | ResumeAfterStabilisation | Resumes after vibration stays low for 60 s |
| OP-11 | HandleDoorOpening | Suspends conservation when the door opens |
| OP-12 | VerifyAndResumeConservation | Resumes only after conditions and sensors are verified |
| OP-13 | SwitchToEmergencyPower | Moves to backup power on power loss |
| OP-14 | RecordIncidentAndShutDown | Logs the incident and shuts down safely (no backup power) |
| OP-15 | AuthoriseBatchRemoval | Allows batch removal only when the chamber is safe |
| OP-16 | SendOperatorAlert | Sends an alert to Mission Control |

## Chamber States (used by the operations)
| ID | State | Meaning |
|---|---|---|
| CH-1 | CH-OFF | No power |
| CH-2 | CH-SELF_CHECK | Testing sensors |
| CH-3 | CH-READY | Monitoring, no batch yet |
| CH-4 | CH-BATCH_LOADED | Profile loaded, waiting for door close |
| CH-5 | CH-CONSERVING | Active conservation |
| CH-6 | CH-CORRECTING | Fixing an out-of-range value |
| CH-7 | CH-PROTECTION | Correction failed; batch protected |
| CH-8 | CH-VIBRATION_HOLD | Risky activities paused |
| CH-9 | CH-DOOR_SUSPENDED | Door opened during conservation |
| CH-10 | CH-EMERGENCY_POWER | Running on backup power |
| CH-11 | CH-SHUTDOWN | Safely shut down |
