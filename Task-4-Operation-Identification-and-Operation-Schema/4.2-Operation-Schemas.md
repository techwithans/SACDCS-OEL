# Task 4.2 – Operation Schemas

> Question: Create a complete Operation Schema for at least 6 operations with the
> fields: Operation name, Description, Inputs, Outputs, Reads, Changes,
> Sends/Alerts, Assumes (precondition), Result (postcondition).

## OP-01 RunSelfCheck
| Field | Value |
|---|---|
| Operation name | RunSelfCheck |
| Description | Tests each essential sensor when the chamber is powered on |
| Inputs | Power-on signal |
| Outputs | SelfCheckResult (PASS / FAIL with list of failed sensors) |
| Reads | Temperature, humidity, vibration, door and power sensors |
| Changes | Chamber state CH-SELF_CHECK → CH-READY (if PASS) |
| Sends/Alerts | OP-16 alert to MCC if any sensor fails |
| Assumes | Chamber is powered and empty |
| Result | All sensors OK → CH-READY (monitoring starts). Any failure → monitoring does NOT start and the failure is logged. |

## OP-03 StartConservation
| Field | Value |
|---|---|
| Operation name | StartConservation |
| Description | Starts active conservation for the loaded batch |
| Inputs | Start command |
| Outputs | ConservationStarted event |
| Reads | Door status, Profile_Loaded flag |
| Changes | CH-BATCH_LOADED → CH-CONSERVING |
| Sends/Alerts | Status update to MCC |
| Assumes | Door_Closed = TRUE ∧ Profile_Loaded = TRUE |
| Result | Conservation is active; OP-04 ReadSensors runs every 10 s |

## OP-05 CorrectTemperature
| Field | Value |
|---|---|
| Operation name | CorrectTemperature |
| Description | Brings chamber temperature back into the batch range |
| Inputs | Current temperature, target range from batch profile |
| Outputs | Cooler/heater command, correction start time |
| Reads | Temperature sensor, batch profile |
| Changes | CH-CONSERVING → CH-CORRECTING; cooler or heater ON |
| Sends/Alerts | "Temperature out of range" warning to MCC |
| Assumes | Chamber is CH-CONSERVING and temperature is outside the range |
| Result | **Verified by sensor (OP-07):** temperature within range within 10 min → back to CH-CONSERVING. Otherwise OP-08 is called. |

## OP-08 ActivateProtection
| Field | Value |
|---|---|
| Operation name | ActivateProtection |
| Description | Emergency protection when correction fails |
| Inputs | Recovery-timeout event (10 min passed) |
| Outputs | Quarantine flag, ChamberCritical signal |
| Reads | Batch ID, current sensor values |
| Changes | CH-CORRECTING → CH-PROTECTION; light exposure reduced; batch status = Quarantined |
| Sends/Alerts | Operator alert (OP-16) + **SafeModeTrigger (E8) to the robot** |
| Assumes | Correction did not succeed within the recovery period |
| Result | Batch cannot be removed; robot enters SAFE_MODE (Task 3, T13) |

## OP-11 HandleDoorOpening
| Field | Value |
|---|---|
| Operation name | HandleDoorOpening |
| Description | Reacts when the door opens during conservation |
| Inputs | Door_Open = TRUE |
| Outputs | ConservationSuspended event |
| Reads | Door sensor, current robot state |
| Changes | CH-CONSERVING → CH-DOOR_SUSPENDED |
| Sends/Alerts | Robot moving → tamper alert + E8. Robot DELIVERING → normal log only. |
| Assumes | Chamber is CH-CONSERVING |
| Result | Normal operation stops and does not resume until OP-12 succeeds |

## OP-15 AuthoriseBatchRemoval
| Field | Value |
|---|---|
| Operation name | AuthoriseBatchRemoval |
| Description | Decides whether a batch may be taken out |
| Inputs | Removal request + PIN or QR code |
| Outputs | ALLOW or DENY (with reason) |
| Reads | Temperature, protection flag, robot state, location |
| Changes | Door lock → unlocked (only if ALLOW) |
| Sends/Alerts | Event log; deny reason sent to MCC |
| Assumes | Robot is DELIVERING at the correct clinic |
| Result | Door unlocked only if the chamber is safe ∧ no protection is active (constraint C-11) |
