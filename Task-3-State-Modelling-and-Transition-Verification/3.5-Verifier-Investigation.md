# Task 3.5 – Verifier Investigation

> Question: Act as a verifier and investigate: (a) Can IDLE → DELIVERING happen?
> (b) What if AVOIDING_OBSTACLE has no transition back? (c) Can AVOIDING_OBSTACLE →
> DELIVERING occur? (d) What happens on CriticalBattery while in AVOIDING_OBSTACLE
> or DELIVERING? Try to find invalid, missing and unsafe transitions.

## (a) Can IDLE → DELIVERING happen?
- **Answer:** No, it must never happen.
- **If it did:** The robot would "deliver" while still at the warehouse, without travelling.
- **Violated:** FR-03 and the scenario rule "a waiting robot must never begin delivering directly".
- **Type:** Invalid transition.
- **Protection:** DELIVERING can only be entered through T06 (from NAVIGATING).
  Command validation (FR-02) rejects the command. Tested in TC-04(a).

## (b) What if AVOIDING_OBSTACLE has no transition back?
- **Answer:** The robot gets stuck forever. This is a **trap state (deadlock)**.
- **Can it still deliver?** No. It can never reach DELIVERING, so the delivery
  fails and the vaccines may spoil.
- **Type:** Missing transition.
- **Fix:** T04 (ObstacleCleared → previous state), plus a 2-minute timeout alert to MCC (FR-04).

## (c) Can AVOIDING_OBSTACLE → DELIVERING occur?
- **Answer:** It must not.
- **If it did:** The robot would open the chamber while still handling an obstacle.
- **Violated:** Scenario rule "never deliver while handling an obstacle" and constraint C-12.
- **Type:** Unsafe transition.
- **Fix:** DestinationReached is ignored in AVOIDING_OBSTACLE (T05). The robot must
  return to NAVIGATING first.

## (d) CriticalBattery in AVOIDING_OBSTACLE or DELIVERING
- **Answer:** The scenario only defines CriticalBattery for NAVIGATING, so
  behaviour here is **undefined**.
- **Risk:** The robot keeps going and its battery dies mid-route with medicine onboard.
- **Type:** Missing transitions.
- **Fix:**
  - T10: AVOIDING_OBSTACLE + CriticalBattery → finish avoiding, then RETURNING.
  - T11: DELIVERING + CriticalBattery → complete the handover (door must not stay open), then RETURNING.
  - If battery drops below 10 %, T13 → SAFE_MODE.
