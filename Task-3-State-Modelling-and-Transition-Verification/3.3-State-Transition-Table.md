# Task 3.3 – State Transition Table

> Question: Build a State Transition Table in the form Current State + Event →
> Next State, with the requirement ID, a Valid? column and verification evidence.

Safe Mode and Link Lost rows are in [3.4](3.4-Safe-Mode-and-Link-Lost-Extension.md).

| T-ID | Current State + Event | Next State | Req ID | Valid? | Evidence |
|---|---|---|---|---|---|
| T01 | IDLE + DeliveryRequest | NAVIGATING | FR-03 | Yes | TC-01 |

| T03 | NAVIGATING + ObstacleDetected | AVOIDING_OBSTACLE | FR-04, HR-04 | Yes | TC-06 |
| T04 | AVOIDING_OBSTACLE + ObstacleCleared | Previous moving state (NAVIGATING or RETURNING) | FR-04 | Yes | TC-06 |
| T05 | AVOIDING_OBSTACLE + DestinationReached | DELIVERING | FR-03 | **No – event ignored** | TC-06 |
| T06 | NAVIGATING + DestinationReached | DELIVERING | FR-03, FR-07 | Yes | TC-01 |
| T07 | DELIVERING + DeliveryComplete | RETURNING | FR-03 | Yes | TC-01 |
| T08 | RETURNING + WarehouseReached | IDLE | FR-03 | Yes | TC-01 |
