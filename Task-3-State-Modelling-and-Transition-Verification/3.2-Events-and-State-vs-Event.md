# Task 3.2 – Events and State vs Event

> Question: Identify all events/conditions and explain the difference between a
> state and an event.

| ID | Event | Meaning |
|---|---|---|
| E1 | DeliveryRequest | An authorised dispatch command is received |
| E2 | ObstacleDetected | An obstacle is found in the path |
| E3 | ObstacleCleared | The path is free again |
| E4 | DestinationReached | The robot has arrived at the clinic |
| E5 | DeliveryComplete | Batch handed over and chamber door closed |
| E6 | WarehouseReached | The robot is back at the warehouse |
| E7 | CriticalBattery | Battery below 25 % |
| E8 | SafeModeTrigger | Battery below 10 %, battery temp above 60 °C, chamber temp critical, or critical fault |
| E9 | LinkLost | No valid message from MCC for 60 s |
| E10 | LinkRestored | Communication is back |
| E11 | SafeModeCleared | Supervisor reset and all values are normal |

## Difference between a State and an Event

| | State | Event |
|---|---|---|
| What it is | A condition the robot **stays in** for some time | Something that **happens at one moment** |
| Duration | Lasts (seconds, minutes, hours) | Instant |
| Example | NAVIGATING | ObstacleDetected |
| Role | Describes *where* the robot is in its life-cycle | *Causes* a move from one state to another |

**Simple way to remember:** The robot *is in* a state. An event *happens to* the robot.
Example: the robot is in NAVIGATING (state); ObstacleDetected happens (event);
now it is in AVOIDING_OBSTACLE (new state).
