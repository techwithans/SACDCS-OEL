# Task 5.2 – Formalised Constraints

> Question: Formalise at least 8 constraints using logical notation (∧, ∨, ¬, →).

**Symbols:** ∧ = AND · ∨ = OR · ¬ = NOT · → = IF ... THEN

| C-ID | Formal Constraint | Read it as |
|---|---|---|
| C-01 | (Train_Approaching ∨ Train_Present) → ¬Barrier_Open | If a train is coming or on the crossing, the barrier is not open |
| C-02 | Train_Approaching → (Lights_On ∧ Alarm_On) | If a train is coming, lights and alarm are on |
| C-03 | Barrier_Open → Crossing_Clear_Confirmed | If the barrier is open, the crossing was confirmed clear |
| C-04 | Robot_Entering → (Barrier_Open ∧ ¬Train_Approaching ∧ ARLCCS_Permission) | If the robot enters, the barrier is open, no train is coming, and permission was given |
| C-05 | Robot_On_Crossing → (Time_On_Crossing ≤ 20) | If the robot is on the crossing, it has been there 20 s or less |
| C-06 | ¬Train_Sensor_OK → (¬Barrier_Open ∧ Operator_Alert) | If the train sensor fails, the barrier is closed and the operator is alerted |
| C-07 | ¬ARLCCS_Link_OK → ¬Robot_Entering | If the link is lost, the robot does not enter |
| C-08 | Barrier_Fault → (¬ARLCCS_Permission ∧ Lights_On ∧ Operator_Alert) | If the barrier is faulty, no permission, lights on, operator alerted |
| C-09 | (Sensor_A ≠ Sensor_B) → (¬Barrier_Open ∧ Event_Logged) | If the sensors disagree, the barrier stays closed and it is logged |
| C-10 | (Robot_State ∈ {NAVIGATING, AVOIDING_OBSTACLE, RETURNING}) → ¬Chamber_Door_Open | If the robot is moving, the chamber door is closed |
| C-11 | Batch_Removed → (2 ≤ Chamber_Temp ≤ 8 ∧ ¬Protection_Active ∧ Robot_State = DELIVERING) | If a batch is removed, temperature is safe, no protection is active, and the robot is delivering |
| C-12 | (Robot_State = DELIVERING) → (At_Destination ∧ Robot_Speed = 0) | If delivering, the robot is stopped at the destination |

## How a monitor checks a constraint
For `A → B`, the constraint is **broken only when A = TRUE and B = FALSE**.
A monitor reads the values every cycle and raises a violation when that happens.
