# Task 5.4 – Detection and Expected Response

> Question: Explain for each violation how the system detects the violation and
> the expected response (alarm, barrier closed, robot stop, Safe Mode, operator
> alert, event logged).

| C-ID | How the system detects it | Expected response |
|---|---|---|
| C-01 | Safety-monitoring unit compares the train sensor with the barrier position sensor | Force barrier closed, sound alarm, deny robot permission, operator alert, event logged |
| C-02 | Light current sensor reads 0 A while a train is approaching | Alarm, deny robot permission, maintenance alert, event logged |
| C-03 | Monitor sees Barrier_Open while the clear flag is FALSE | Re-close barrier, operator alert, event logged |
| C-04 | Robot's onboard guard checks all three conditions at the stop-line | Robot stops before the stop-line, MCC alert, event logged |
| C-05 | Robot timer passes 20 s while GPS shows it on the crossing | ARLCCS keeps barrier closed and alarm on, robot forced to clear the tracks, then Safe Mode, operator alert, event logged |
| C-06 | Sensor heartbeat missing for more than 2 s | Barrier closed, lights and alarm on, operator alert, event logged |
| C-07 | No reply from ARLCCS within 10 s (HR-03) | Robot stops at the stop-line and waits, MCC alert, event logged |
| C-08 | Position sensor does not match command after 10 s | Withdraw permission, lights on, maintenance and operator alert, event logged |
| C-09 | Monitor compares Sensor_A and Sensor_B every cycle | Treat as train present, barrier closed, "sensor mismatch" event logged, operator alert |
| C-10 | Door sensor (OP-04) reports open while robot state is moving | Robot Safe Mode (E8), conservation suspended (OP-11), tamper alert, event logged |
| C-11 | OP-15 checks temperature and protection flag before unlocking | Door stays locked, batch Quarantined, operator alert, event logged |
| C-12 | Wheel encoder shows speed > 0 while state is DELIVERING | Robot stopped, door locked, Safe Mode, event logged |

## Response Summary
| Response | Used for |
|---|---|
| Alarm | C-01, C-02, C-05, C-06 |
| Barrier closed | C-01, C-03, C-05, C-06, C-09 |
| Robot stop | C-04, C-05, C-07, C-12 |
| Safe Mode | C-05, C-10, C-12 |
